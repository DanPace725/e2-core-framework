## Working Read

The staged document is not only an expansion of the prior Relational Viscosity note. It is a synthesis bundle with several separable candidate moves:

1. `Vis_R` is clarified as a substrate-side measurement/property of CRS under load.
2. `V_r` is reframed as an agent-side measurement of local possibility rather than the underlying capacity itself.
3. `V_r` and `Vis_R` are treated as a coupled Zone 3 measurement object.
4. CRS is refined through an interface-substrate ontology: local interface fields generated at agent boundaries can bind into emergent collective substrate.
5. Boundary Dynamics is complemented by horizon language: boundary differentiates; horizon limits access; remainder persists beyond horizon; occlusion totalizes the horizon.
6. Redshift is proposed as a bias-field attenuation mechanism for signals beyond a current resolution frame.
7. The relational primitives are used as an analytical sequence for inquiry: `P2, P3, P4 -> P5 -> P1 -> P6`.

The load-bearing claim is therefore:

```text
Agent state, substrate state, and interface condition have to be diagnosed together.
The workable unit is not isolated V_r or isolated Vis_R, but the coupling regime
between agents, boundaries, and the substrate they help generate and inhabit.
```

Integration implication:

The staged reframe is significant and should not be silently substituted. It can preserve the current insight by distinguishing:


Recommended handling:

Treat the `V_r` reframe as a revision candidate or addendum to Relational Volition, not as a direct overwrite. The original document's "capacity" language is stable enough to keep, but it needs a measurement/object distinction if the framework is going to support instrumentation.

## Collision And Risk Review

### 1. `V_r` Reframe Collides With Current Source Language

The current Relational Volition source defines `V_r` as capacity. The staged document says `V_r` is a measurement of capacity. This is a real refinement, not a cosmetic edit.

Resolution:

Use a layered distinction. Preserve the original insight that volition concerns coherence-preserving local possibility, but name `V_r` as the observable measurement rather than the underlying object.

### 2. "Horizon" Should Not Be Called A Primitive Without Qualification

The staged document calls horizon an epistemic primitive. That wording can accidentally sound like the primitive layer is being expanded.

Resolution:

Use "epistemic companion construct," "access-limit construct," or "epistemic correlate of boundary." If the word primitive is retained, qualify it locally as "epistemic primitive" and explicitly distinguish it from the six relational primitives.

### 3. Physics Analogies Could Over-Mechanize Too Early

Boundary layers, double layers, micelles, emulsions, redshift, and universality classes are useful, but the current document has not yet derived formal relational equivalents.

Resolution:

Treat physics precedents as disciplined analogical scaffolding and candidate formal anchors. Do not promote them as proof until the mapping is worked.

### 4. Interface Ontology Could Sound Like Agents Create Substrate From Nothing

The document already handles this with the deep CRS / local interface film / bound collective substrate distinction. That distinction is load-bearing and should be preserved.

Resolution:

Any promoted version should state clearly that agents are always already substrate-coupled at the deep level, while local interface phenomena can generate bound substrate at the next scale.

### 5. Scale Invariance Is A Research Program, Not Yet A Result

The claim that boundary invariants apply from quark to civilization is coherent with the framework but very strong.

Resolution:

Promote as a methodological hypothesis. Put empirical and formal characterization into open questions.

### 6. Single-Artifact Promotion Would Create Maintenance Drag

The staged document combines metric design, ontology, boundary epistemology, social diagnosis, practice architecture, and methodology. It is coherent as a conversation synthesis, but too dense as one canonical source artifact.

Resolution:

Split into smaller candidate artifacts with explicit cross-links.
