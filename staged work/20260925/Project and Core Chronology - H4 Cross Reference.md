# Project and Core Chronology — H4 Cross Reference

Status: staged exploratory chronology, 2026-09-25. Companion to `Outbound Release Process v0.2.md`, its v0.2 review, and the outbound project matrix. This is a source index for later comparison, not a claim that E² originated any project or that a project's date proves conceptual influence.

## How To Use This Record

The **project artifact**, **actual practice or receiver event**, **earliest extant E² concept**, and **active Core articulation** have different dates. An initial commit establishes that a repository snapshot existed by that day. It rarely establishes when the idea began or when anyone used the project. A dated run establishes activity, not necessarily outward contact. A recalled use period is valuable evidence but has different precision from a dated message or run.

The three evidence appendices cover every candidate row of the comparison matrix, including unknowns, and provide paths, commit IDs, and limits:

- `Project Chronology Evidence - E2.md` — 26 E² Project Matrix entries.
- `Project Chronology Evidence - Coding and Public.md` — 29 Coding sibling entries, four public GitHub repositories, and the Fast Fashion essay.
- `H4 Core Concept Chronology Evidence.md` — dated Exposure, Stewardship, Boundary Dynamics, GDD, and analogous source claims.

These are working inventories. They were not built from a shared, continuous Git history: the E2 root has no usable Git commits, while some sibling projects and Core have their own repositories. Dates for the four public GitHub repositories came from their Git histories via temporary filtered bare clones. Private exports were not opened. No filesystem creation or modified time was used as an origin date.

## What This Does And Does Not Say About H4

There are project artifacts before the extant Exposure Protocol text: ChatGPT_history_parser, Aviary, MindiAI, ACE, PortfolioSite, the policy graph, Resonance-OS, DocFlow, and the shared ORMD/Open RMD history. Those artifacts establish **possible earlier work**, not an earlier instance of the full Outbound practice. The most relevant pre-Exposure practice evidence is ACE family use: the user's “over a year” report on 2026-09-25 puts some use before 2025-09-25, one day before the located Exposure text. That ordering is conditional on the retrospective duration and says nothing yet about whether ACE's operating practice shaped the later protocol. DocFlow's “years” of workplace use may also be earlier, but its interval is too loose for a precise comparison. MindiAI's 2024 implementation predates Exposure, while the father's reported use and the data-export handoff remain undated.

The named Intervention Stewardship draft is dated 2026-06-09, after several project artifacts and runs, but Reverent Stewardship and disclosure/containment predecessors are earlier. Thus a project date before June 2026 does not show the project was independent of stewardship ideas. Several of the strongest reported receiver events still cannot be placed on the date axis.

**Provisional H4 result:** the record supports a real chronological possibility that some outward practices preceded their formal description, especially ACE family use and perhaps DocFlow. It does **not** yet establish that the corpus derived its concepts from those practices, or which E² concepts were already active informally. The next discriminating evidence would be a few dated practice receipts (with receiver privacy preserved) and dated drafts or notes showing which project experiences the Exposure/Stewardship authors explicitly drew on. Keep `order unresolved` where those links are absent.
