## Reading the dates

- Local Git dates below are commit author dates shown by `git log --all`; dates have day precision. They prove that a repository snapshot existed by then, not when the idea, coding, or use began. Local repository history may be partial, shallow, rewritten, or absent.
- A first dated document is a *first extant record* only. File-system creation/modified timestamps were not treated as origin dates because copying and restoration can reset them.
- “Active interval” means only the span from earliest to latest accessible commit in the available local history. A single commit is a snapshot, not proof of ongoing activity. No inference of inactivity is made after the last commit.
- The user-reported usage/event statements in the companion matrix are useful evidence but have no contemporaneous receipt attached unless noted. They are labeled as retrospective reports, not verified dates.
- The scan excluded private data exports, including `acebackup` and `mindi export`; no personal exported conversations or data payloads were opened.
- After the first web-page pass, a metadata-only bare Git clone of each public repository supplied commit author/committer dates. The temporary clones were removed after reading commit metadata; no public project was installed or run.
