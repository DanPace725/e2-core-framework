# Mobile drafts

Pages CMS creates structured Markdown drafts in this folder. A draft belongs to the staged inbox and does not become part of the active Core Framework until it has passed through the integration process in `AGENT_INTEGRATION_PROCESS.md`.

Expected frontmatter:

```yaml
---
title: Example draft
status: staged
author: Example author
---
```

Use the body for the candidate claim, supporting reasoning, open questions, and any intended framework connections. Preserve uncertainty instead of presenting an early draft as settled doctrine.
