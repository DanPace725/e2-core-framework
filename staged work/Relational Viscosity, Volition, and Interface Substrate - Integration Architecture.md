## Track A: Viscosity / Volition Coupling

Candidate artifact:

```text
staged work/Relational Viscosity and Volition Coupling - Candidate Source.md
```

Status recommendation: promote as candidate source after review.

Parent corpus:

- `Semantic Substrate/CRS.md`
- `Semantic Substrate/Relational Volition.md`
- `Semantic Substrate/flow_operators_provisional.md`
- `Semantic Substrate/sign_mediated_flow_routing.md`

Core claims to extract:

- `Vis_R` is substrate-side measurement/property under load.
- `V_r` is agent-side measurement of local coherence-preserving possibility.
- Acts, not measurements, replenish or drain agent and substrate capacity.
- `V_r` and `Vis_R` form a coupled Zone 3 measurement object.
- Diagnosis should be regime-shaped rather than magnitude-shaped.

Keep these coupling patterns:

| Pattern | Meaning |
| --- | --- |
| compensation upward | high `V_r` masks low `Vis_R`; output looks healthy while substrate fails |
| coherence-preserving refusal | high `V_r` withholds from participation that would violate field coherence |
| performative generation | low `V_r` agency creates apparent viscosity through theater or harmony pressure |
| withdrawal | absent or withdrawn agency makes functional substrate appear empty |

Collision to resolve:

The current Relational Volition source defines `V_r` as capacity. The candidate should avoid a blunt replacement by distinguishing underlying capacity from the measurement of that capacity under present conditions.

Minimum promoted form:

```text
Relational Volition names local coherence-preserving possibility in an agent.
V_r is the measurement of that possibility under present agent, substrate, and field conditions.
Relational Viscosity names the substrate-side capacity to hold friction and movement under load.
Vis_R is the measurement/property of that substrate condition.
The two are coupled in Zone 3 and should be diagnosed by regime.
```

## Track B: Interface Substrate Ontology

Candidate artifact:

```text
staged work/Interface Substrate Ontology - Candidate Source.md
```

Status recommendation: draft next after Track A stabilizes.

Parent corpus:

- `Semantic Substrate/boundary_dynamics.md`
- `Semantic Substrate/sign_mediated_flow_routing.md`
- `Semantic Substrate/Emergence_Determination_Foreclosure.md`
- `Semantic Substrate/CRS.md`

Core claims to extract:

- CRS can be understood through both bulk-medium and interface-phenomenon frames.
- Local interface fields are generated at agent boundaries.
- At sufficient density and coherence, interface fields bind into emergent collective substrate.
- Bound substrate then mediates and modulates the agents whose interfaces helped form it.
- Agents do not precede deep substrate; they can generate local interface phenomena that precede bound collective substrate at the next scale.

Preserve this three-scale distinction:

```text
deep CRS
  -> ontological ground that allows agents to exist

local interface films
  -> fast boundary-layer phenomena generated in proximity

bound collective substrate
  -> emergent continuous layer formed by coherent interface binding
```

Physics precedents to include carefully:

- boundary layer
- double layer
- Leidenfrost layer
- self-assembled monolayers and lipid bilayers
- emulsions and surfactants

Guardrail:

These are disciplined analogical anchors, not proof. The relational equivalents need formal work before the artifact should present them as mechanism in the strong sense.

## Track C: Boundary And Horizon

Candidate artifact:

```text
staged work/Boundary and Horizon - Candidate Source.md
```

Status recommendation: draft as standalone candidate source.

Parent corpus:

- `Semantic Substrate/boundary_dynamics.md`
- `Semantic Substrate/Signal as Bias Field.md`
- `Semantic Substrate/sign_mediated_flow_routing.md`

Core claims to extract:

- Boundary is the structural differentiation that permits form.
- Horizon is the access-limit generated by that form relative to an observer.
- Resolution produces both boundary and horizon.
- Remainder persists beyond the horizon.
- Occlusion is horizon-totalization: mistaking the horizon for the whole.
- Redshifted remainder is signal from beyond the current resolution frame attenuated below recognition.

Five-term system:

| Term | Function |
| --- | --- |
| resolution | stabilizes coherence by accepting loss |
| boundary | cut that permits form |
| horizon | limit of access produced by form |
| remainder | what exceeds the horizon |
| occlusion | treating the horizon as reality's edge |

Guardrail:

Use "epistemic companion construct" rather than unqualified "primitive." The six relational primitives remain the settled grammar of the current framework.
