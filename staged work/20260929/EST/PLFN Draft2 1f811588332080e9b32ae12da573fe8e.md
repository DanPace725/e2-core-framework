## 0 Why PLFN?

PLFN (Proto‑Liminal Field Notation) is an experimental “thought‑syntax” designed to:

1. **Expose orientation.** Every semantic atom carries its *vector* (intention, direction, affect).
2. **Preserve productive ambiguity.** Meaning clouds stay fluid until needed.
3. **Travel across channels.** The same glyph set works in handwriting, typing, gesturing, or code.
4. **Scale recursively.** Layers add nuance without breaking earlier layers.

> Core hypothesis: Explicit vector‑tagging + lightweight field operations can lower friction between diverse cognitive styles while keeping language hackable and alive.
>

## 1 Layer 1 — Seed Syntax (v0.1 recap)

```
(A) Determine V  →  [U] Understand | [BU] Be Understood
(B) (term)ᵁ / (phrase)ᴮᵁ / (vector)ᴬ …
(C) a / b / c   → loose cluster pointer
(D) Subscripting for branch variants  (Vᵤ, Vᴮᵁ, U₀, U₁…)
(E) Math logic borrow  (⇒, ∴, Σ, ∂…)
(F) Programming borrow  define f(x): …
(G) UX shortcuts  “/” for proximity etc.

```

## 2 Layer 2 — Extended Notation (v0.2)

### 2.1 New Superscript Codes (Orientation / Act)

| Code | Meaning | Typical Use |
| --- | --- | --- |
| **ᴿ** | *Reflect* — intra‑self inquiry | `(fear)ᴿ` = noticing own fear |
| **ᑫ** | *Question* — outward uncertainty | `(algorithm)ᑫ` = “what is this algo?” |
| **ᵀ** | *Test* — hypothesis probe | `(loop)ᵀ` |
| **ᴾ** | *Propose* — suggestion / design | `(path)ᴾ` |
| **ᴄ** | *Connect* — linking disparate fields | `(gravity / bell‑curve)ᴄ` |

### 2.2 Subscript Field Channels

- `U₀, U₁ … Uₙ` — reception depth gradient (passive→active→embodied)
- `B₀, B₁` — broadcast scope (1‑to‑1 vs 1‑to‑many)
- `Cₓ` — context id (thread or document key)

### 2.3 Field Operators

- **Concatenate**: `α ⊕ β` merges fields retaining both vectors.
- **Collapse**: `[α β]↓` selects a dominant token, freezing ambiguity.
- **Fork**: `⤳{branch₁, branch₂}` spawns divergent semantic paths.
- **Map** (builder pattern): `map⟦f⟧{a / b / c}` → applies *f* across cluster.

### 2.4 Macro Definition Syntax

```
macro define ⟦name⟧(args…):
    body → may include any PLFN tokens
    return [output‑field]

```

Macros allow reusable templates (e.g., meeting minutes, code review comments).

## 4 Layer 4 — Multimodal Bridges

1. **Handwriting:** adopt ^ and _ marks above/below baseline + circled superscripts.
2. **Gesture:** two‑finger draw superscript in air; palm twist for subscript.
3. **Code:** `.plfn` files compile to JSON‑LD graph for programmatic parsing.
4. **Speech:** optional spoken prefixes "sup‑U", "sub‑1" for accessibility.
